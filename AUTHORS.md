# Authors and provenance

This repository preserves the full Git history of the original `lintweaker/mytekusb2` project. The per-file copyright notices and the Git history remain the authoritative record of authorship.

## Original and historical authors

- **Jurgen Kramer** (`lintweaker`) — original Mytek Stereo192-DSD USB2 adaptation and primary maintainer of this repository's driver code. The source headers identify the Mytek adaptation and copyright as Jurgen Kramer.
- **Torsten Schenk** — author of the TerraTec DMX 6Fire USB ALSA driver on which the Mytek driver was based. The original Mytek README explicitly credits this work.
- **Clive Messer** (`clivem`) — historical contributor, including Makefile/packaging changes preserved in the Git history.

## Current maintenance

- **Jan Taplick** (`jantaplick`) — current fork maintenance, recent-kernel compatibility work, Volumio/Raspberry Pi validation, firmware re-probe fix, packaging and blob-free distribution work.

## Attribution policy

No historical authorship is replaced or reassigned by this fork. Existing copyright notices are retained. New substantial contributions should keep their Git authorship and, where appropriate, add a short note here.

The proprietary Mytek firmware files are **not** authored by this project and are **not** distributed by this repository.
