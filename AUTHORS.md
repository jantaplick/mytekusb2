# Authors and provenance

This fork preserves the full Git history of the original `lintweaker/mytekusb2` project. Existing per-file copyright notices and Git authorship remain the authoritative record.

## Original and historical authors

- **Jurgen Kramer** (`lintweaker`) — original Mytek Stereo192-DSD USB2 adaptation and primary maintainer of the Mytek driver. The source headers identify the Mytek adaptation and copyright as Jurgen Kramer.
- **Torsten Schenk** — author of the TerraTec DMX 6Fire USB ALSA driver on which this Mytek driver was based. The original README explicitly credits his work.
- **Clive Messer** (`clivem`) — historical contributor; contributions preserved in Git history include Makefile/packaging work and ARM-related fixes/feedback.

## Current maintenance

- **Jan Taplick** (`jantaplick`) — recent-kernel maintenance, Raspberry Pi / Volumio validation, firmware re-probe fix, private packaging support and blob-free public distribution work.

## Attribution policy

This fork does not replace or rewrite historical authorship. Existing copyright notices are retained. New substantial contributions should preserve Git authorship and, where useful, be added here.

The proprietary Mytek firmware files are not authored by this project and are not distributed by this repository.
